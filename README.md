# Student Management System

A simple Python application that manages student records using JSON file storage.

## Features

- Add a new student
- View all students
- Search student by name
- Update student details
- Delete a student
- Saves data permanently using JSON
- Automatically loads data when the program starts
- Handles empty or invalid JSON files using exception handling

## Technologies Used

- Python 3
- JSON
- File Handling
- Exception Handling (try/except)
